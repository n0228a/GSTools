Bundled MPS output figures
==========================

This directory contains precomputed PNG figures used by selected MPS gallery
examples. They are bundled so the documentation can show high-quality results
without running the expensive simulations during every Sphinx-Gallery build.

The figures are generated by the corresponding scripts in ``examples/13_mps``
when ``generate_output`` is set to ``True`` inside the script.

Input provenance and third-party license information is documented in
``../input/LICENSE.txt``. In particular:

* ``radial_nonstationarity.png`` and ``bivariate_joint_channels.png`` are
  derived from the bundled GeoDataSets/Strebelle channel input.
* ``continuous_stone_conditioning.png`` is derived from the bundled GAIA-UNIL
  stone texture.
* ``multivariate_context_channels.png`` is generated from synthetic GSTools
  documentation input.
